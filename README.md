# StudyPlan

Онлайн-планировщик учебы для студентов.

Учебный проект: Монцева А.Д., группа ПИМ-24-2.
Начальная версия для этапа 25%.

## Цель проекта

Помочь студенту хранить расписание и учебные задания
в одном месте и следить за сроками сдачи.

## Что реализовано

- Главная страница и меню разделов.
- База SQLite с таблицами предметов, заданий и занятий.
- Форма добавления задания.
- Сохранение названия задания, предмета и срока сдачи.
- Вывод сохраненных заданий по сроку сдачи.
- Проверка пустых полей и названия из одних пробелов.
- Сохранение записей после перезапуска приложения.

## Что запланировано

- Добавление и просмотр расписания.
- Изменение и удаление заданий.
- Отметка выполненных заданий.
- Фильтры по предмету и статусу.
- Вывод ближайших и просроченных заданий.

## Инструменты

Python, Streamlit, SQLite, Visual Studio Code и GitHub.

## Файлы проекта

- app.py — интерфейс приложения.
- database.py — создание таблиц и работа с базой.
- requirements.txt — список библиотек.
- studyplan.db — база, создается при первом запуске.

## Первый запуск на Mac

В терминале из папки проекта выполнить по очереди:

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py

## Повторный запуск

source .venv/bin/activate
python -m streamlit run app.py

Для остановки приложения нажать Control + C в терминале.

## Выполненные проверки

1. Заполненное задание сохраняется и появляется в списке.
2. После перезапуска приложения запись остается.
3. Пустое название задания не принимается.
4. Название из одних пробелов не принимается.
5. Пустой предмет не принимается.
6. Без даты сдачи задание не сохраняется.
